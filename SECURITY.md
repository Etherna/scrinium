# Security policy

## Reporting a vulnerability

Please do not open a public issue or a Jira work item for a security problem.

Report it privately through GitHub: **Security → Report a vulnerability** on this repository. We acknowledge reports within a few working days and keep you informed until the fix is released.

## Disclosure

The report stays private until a fixed version is released. Once it is, the tracking work item on our Jira (https://etherna.atlassian.net) becomes public and the fix is listed in the release notes with credit to the reporter, unless the reporter prefers otherwise.
